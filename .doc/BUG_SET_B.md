# セットB

対象バグ: #3 真っ白な画面 / #4 リロードなし / #9 キーボード

---

## #3 — 真っ白な画面

### ユーザーの声

「前に登録したアクティビティを見ようと思って日付を変えたのですが、何も表示されず真っ白な画面になります。データがないのか、表示に失敗しているのか分かりません。」

### 再現手順

1. タイムライン画面を開く。
2. アクティビティが登録されている、または登録されていない日付を選択する。

**期待される動作**
選択した日付にアクティビティが存在する場合は一覧が表示され、存在しない場合は「アクティビティがありません」などの空状態（Empty State）が表示される。

**実際の動作**
選択した日付に応じたアクティビティ一覧も空状態も表示されず、何も表示されない画面になる。

## #4 — 新しく追加したアクティビティがアプリを再起動するまで表示されない

### ユーザーの声

「アクティビティを追加して保存したのに、タイムラインへ戻っても表示されません。アプリを再起動して初めて表示されました。本当に保存されたのか不安になります。」

### 再現手順

1. タイムラインを開く（既存データを読み込む）
2. 「＋」ボタンから新しいアクティビティを追加して保存する
3. タイムラインへ戻る

### 期待される動作

タイムラインが更新され、新しく追加したアクティビティがすぐ表示される。

### 実際の動作

タイムラインが更新されず、アプリを強制終了して再起動するまで表示されない。

## #9 — キーボードが保存ボタンを隠してしまう

### ユーザーの声

「メモ欄を入力するとキーボードが表示されて、画面下の保存ボタンが隠れてしまいます。保存するには一度キーボードを閉じなければならず不便です。」

### 再現手順

1. 「アクティビティ追加」画面を開く
2. メモ欄をタップしてキーボードを表示する

### 期待される動作

キーボード表示時も画面がスクロールまたはリサイズされ、保存ボタンが常に表示・操作できる。

### 実際の動作

スクロールビュー等によるレイアウト調整がないため、キーボードによってメモ欄や保存ボタンが隠れてしまう。
