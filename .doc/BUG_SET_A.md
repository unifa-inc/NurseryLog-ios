# セットA

対象バグ: #1 真っ白な画面 / #2 日付フォーマット / #5 タイトルが空でも保存できてしまう

---

## #1 — 真っ白な画面

### ユーザーの声

「前に登録したアクティビティを見ようと思って日付を変えたのですが、何も表示されず真っ白な画面になります。データがないのか、表示に失敗しているのか分かりません。」

### 再現手順

1. タイムライン画面を開く。
2. アクティビティが登録されている、または登録されていない日付を選択する。

**期待される動作**
選択した日付にアクティビティが存在する場合は一覧が表示され、存在しない場合は「アクティビティがありません」などの空状態（Empty State）が表示される。

**実際の動作**
選択した日付に応じたアクティビティ一覧も空状態も表示されず、何も表示されない画面になる。

---

## #2 — アクティビティ詳細画面の日付表示形式が不自然

### ユーザーの声

「アクティビティの詳細を開くと、タイムラインとは違う日付表示になります。『29/06/2026 10:00 PM』と表示されていて、他の画面と統一されていないので違和感があります。」

### 再現手順

1. タイムラインから任意のアクティビティをタップして詳細画面を開く
2. 詳細画面の日付表示とタイムラインの日付表示を比較する

### 期待される動作

アプリ内で日付・時刻の表示形式が統一されていること（例：`2026年06月29日(月) 07:00`）

### 実際の動作

詳細画面では `dd/MM/yyyy h:mm a` 形式（例：`29/06/2026 10:00 PM`）で表示される。

---

## #5 — タイトルが空でも保存できてしまう

### ユーザーの声

「タイトルを入力し忘れたまま保存できてしまいました。タイトルのない記録が増えてしまい、何の記録だったのか分からなくなります。」

### 再現手順

1. 「アクティビティ追加」画面を開く
2. タイトルを未入力、または空白文字のみ入力した状態にする
3. 「保存」をタップする

### 期待される動作

タイトルに有効な文字列が入力されるまで、保存ボタンは無効になっている。

### 実際の動作

タイトルが空でも保存ボタンが有効なままで、そのまま保存できる。
