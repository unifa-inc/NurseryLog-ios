# セットC

対象バグ: #1 真っ白な画面 / #7 並び順 / #8 戻るボタン

---

## #1 — 真っ白な画面

### ユーザーの声

「前に登録したアクティビティを見ようと思って日付を変えたのですが、何も表示されず真っ白な画面になります。データがないのか、表示に失敗しているのか分かりません。」

### 再現手順

1. タイムライン画面を開く。
2. アクティビティが登録されている、または登録されていない日付を選択する。

**期待される動作**
選択した日付にアクティビティが存在する場合は一覧が表示され、存在しない場合は「アクティビティがありません」などの空状態（Empty State）が表示される。

**実際の動作**
選択した日付に応じたアクティビティ一覧も空状態も表示されず、何も表示されない画面になる。

## #7 — タイムラインのアクティビティが時間順に並ばない可能性がある

### ユーザーの声（コードレビューより）

「タイムラインのアクティビティが、登録した時間順に並んでいないことがあります。特定の条件で発生するようですが、毎回ではないため気づきにくいです。」

### 確認手順（コードレビュー）

1. Timeline画面を開く
2. 異なる時間のアクティビティを複数登録する
3. タイムラインに表示されるアクティビティの順番を確認する

### 期待される動作

タイムラインのアクティビティが、登録時刻の順番（古い順／新しい順）に正しく並んでいる。

### 実際の動作

アクティビティの取得順に依存して表示されるため、登録時刻の順番と異なる順序で表示される場合がある。

## #8 — 戻るボタンに前画面のタイトルが表示される

### ユーザーの声

「私のiPhoneでは問題ないのですが、子どもが使っている古いiPadだと戻るボタンに『タイムライン』と表示されます。同じアプリなのに表示が違っていて不思議です。」

### 再現手順

1. タイムライン画面から「＋」をタップする
2. 左上の戻るボタンを確認する

### 期待される動作

端末や iOS のバージョンにかかわらず、戻るボタンには前画面のタイトルが表示されない。

### 実際の動作

端末や iOS のバージョンによって、戻るボタンの表示が異なる。一部の環境では、前画面のタイトル（「タイムライン」）が表示される。
